# Sound Composer Audition Lab

Public audition build for the Place Memory Sound Composer experiment.

- 20 deterministic 60-second variations
- the same Memory/Composer mapping for every candidate
- only the seed changes
- objective audio QA was measured from the original 48 kHz stereo WAV renders
- browser audio is AAC 128 kbps for lightweight delivery
- `development ranking` is a development-risk ranking, not an objective human-pleasantness score
- human `好き / 普通 / 微妙` ratings stay in the browser until exported as JSON

This repository contains generated audition audio and evaluation output only. It does not contain Place Memory application source code, source photos, or private Moment input.
